DEPLOYMENT · VULTR · WAVEHOUSE DEMO

wavehouse-vultr

Desired state for the public WaveHouse analytics demo: the live GitHub stats dashboard for Wave-RF/WaveHouse, computed by a self-hosted WaveHouse + ClickHouse stack on one guarded Vultr instance.

See it live: stats.bigconfig.space — every number, chart, and event flows through the WaveHouse gateway; the feed streams over SSE as the anonymous read-only role.

What is tracked here

colors.yml (the only editable desired state), the installed wavehouse Package Skill payload and lockfile, a root launcher copied from that payload, toolchain files, and documentation. Credentials live in gitignored .envrc.private; generated output in .colors/ is never committed.

Lifecycle

direnv allow
./green build
./green create --dry-run
./green create

Build and dry-run are credential-free. Real creation converges the instance, the proxied Cloudflare record, and the Compose stack, backfills GitHub history, starts the live poller, and ends with public HTTPS and data acceptance checks. Deletion stays guarded by compute-prevent-destroy: true.
